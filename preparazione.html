Corso introduttivo al software statistico R

Prepararsi al corso

Prima dell’inizio del corso è necessario installare i programmi e i pacchetti che useremo e scaricare la cartella con i dati. Ti chiediamo di farlo qualche giorno prima del corso, così da avere il tempo di risolvere eventuali problemi.

Installare R, RTools e RStudio

Sul tuo computer devono essere installati R, RTools (solo Windows) e RStudio, preferibilmente in quest’ordine: R → RTools → RStudio.

R

Scarica R da CRAN, nella sezione “Download and Install R”, scegliendo la versione per il tuo sistema operativo (Windows, macOS o Linux).

  • L’ultima versione disponibile è la 4.6.1 (24 giugno 2026). Non è obbligatorio avere l’ultima versione, ma è consigliabile non restare troppo indietro.
  • Sullo stesso computer possono essere installate più versioni di R. In questo caso, controlla che RStudio usi la più recente: menu Tools > Global Options > General > R version.

RTools (solo Windows)

RTools serve per installare alcuni pacchetti a partire dal codice sorgente. Scaricalo da questa pagina scegliendo la versione che corrisponde alla tua versione di R (per esempio RTools 4.5 per versioni a partire da 4.5).

Su macOS non è necessario installare Rtools

RStudio

Scarica RStudio Desktop.

Installare i pacchetti

Apri RStudio, copia il codice qui sotto nella Console e premi Invio. L’installazione può richiedere diversi minuti. Lo stesso codice è nello script pacchetti_da_istallare.R (nella cartella dei materiali): dopo averlo aperto, selezionalo tutto e premi Run.

# Installa {pacman} se non è già presente
if (!require("pacman")) install.packages("pacman")

# Installa (o aggiorna) e carica tutti i pacchetti del corso
pacman::p_load(
  rio,          # importare ed esportare i dati
  openxlsx,     # gestione speciale dei fogli Excel
  remotes,      # installazione di pacchetti da sorgenti esterne
  here,         # percorsi relativi dei file
  tidyverse,    # gestione e visualizzazione dei dati
  skimr,        # panoramica dei dati
  epikit,       # funzioni utili per l'epidemiologia
  janitor,      # pulizia dei dati e tabelle
  gtsummary,    # tabelle descrittive e statistiche
  cowplot,      # combinare grafici
  RColorBrewer, # scale di colori
  gghighlight,  # evidenziare un sottoinsieme
  ggrepel,      # etichette intelligenti nei grafici
  ggExtra,      # grafici avanzati
  tsibble,      # settimane epidemiologiche
  viridis,      # colori adatti ai daltonici
  scales,       # funzioni di supporto per i grafici
  broom,        # tabelle ordinate dei risultati dei modelli
  rstatix,      # test statistici
  ggfortify,    # grafici dei risultati dei modelli
  MASS,         # regressione binomiale negativa
  epitools,     # analisi univariata
  performance,  # valutazione dei modelli di regressione
  epiR,         # rischi relativi aggiustati per strati
  rmarkdown,    # report in HTML, Word, PDF
  knitr,        # génération de rapports
  flextable     # tabelle HTML per i report
)

Se al termine non compaiono messaggi di errore (in rosso, con la parola Error), i pacchetti sono installati correttamente. Gli avvisi (Warning) di solito si possono ignorare.

Se un pacchetto non si installa e R chiede “Do you want to install from sources the packages which need compilation?”, rispondi no: verrà installata la versione già pronta del pacchetto. Se invece l’errore riguarda un solo pacchetto, prova a installarlo da solo, per esempio con install.packages("sf"), e poi esegui di nuovo il codice qui sopra.Se il problema persiste, copia il messaggio di errore e mandalo ai responsabili del corso prima dell’inizio.

Scaricare i materiali del corso

Per scaricare i dati e gli script del corso, clicca qui e salva il file compresso. Estrai la cartella prog_stat_mepi in un punto qualsiasi del tuo computer (per esempio in Documenti): durante il corso lavorerai al suo interno. Crea un progetto RStudio dentro la cartella prog_stat_mepi (lo vedremo passo passo nella sessione 1).

La cartella contiene:

  • data: i dati usati nelle esercitazioni e, dentro data dictionaries, i dizionari dei database;
  • scripts/backup/: le versioni complete (soluzioni) degli script del corso, con nomi backup_*.R;
  • outputs: qui salverai i grafici e le tabelle che produrrai;
  • pacchetti_da_istallare.R: lo script per installare tutti i pacchetti (vedi sezione sopra).
